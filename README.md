# atuf-installer

This repository holds the source code for the Atuf Linux installer application.

The installer is designed to be:
- User-Friendly
  - Simple guided steps for all users.
- KDE-Native
  - Built using Qt/QML for a seamless Plasma look and feel.
- Robust
  - Handling partitioning, package installation and bootloader setup reliably.
